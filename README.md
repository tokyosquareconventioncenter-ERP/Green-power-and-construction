# ⚡ বিজলী কন্ট্রাক্টর (Bijli Contractor) — ইলেকট্রিক্যাল সাইট ও কর্মী হিসাব

একটি বিশ্বস্ত, প্রডাকশন-রেডি, মোবাইল-ফাস্ট PWA (Progressive Web App) যা বাংলাদেশের ইলেকট্রিক্যাল কন্ট্রাক্টরদের জন্য তৈরি। এটি দিয়ে দৈনন্দিন কর্মী হাজিরা, ওভারটাইম, দৈনিক নগদ টাকা নেওয়া, সাইটভিত্তিক আয়, দৈনন্দিন খরচ ও সার্বিক লাভ-ক্ষতির হিসাব সহজেই পরিচালনা করা যায়।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **দুইটি ইউজার রোল (Two User Roles):**
   - **👑 মালিক (Owner):** সর্বময় নিয়ন্ত্রণ। সকল ডেটা দেখা, এডিট ও ডিলিট করা, কর্মী ও সাইট যুক্ত করা, ফরম্যান অ্যাকাউন্ট তৈরি করা, বেতন ও বোনাস সমন্বয় করা, সারাংশ (Summary) ও রিপোর্ট দেখা এবং CSV / PDF ডাউনলোড।
   - **🛠 ফরম্যান (Foreman):** শুধুমাত্র হাজিরা, আয় ও খরচ ইনপুট করতে পারে। কোনো পুরনো হিসাব এডিট বা মুছতে পারে না, এবং সংবেদনশীল অর্থনৈতিক হিসাব দেখতে পারে না।

2. **হাজিরা ও ওভারটাইম (Attendance & Overtime):**
   - **দৈনিক হাজিরা ইনপুট:** তারিখভিত্তিক সকল কর্মীর উপস্থিতি, সাইট, ওভারটাইম (৳) ও দৈনিক নেওয়া টাকা (৳) এক ক্লিকে সেভ করুন।
   - **৩১ দিনের হাজিরার ঘর:** ক্যালেন্ডার গ্রিড ভিউ যেখানে ট্যাপ করে হাজিরা পরিবর্তন করা যায় (✓ উপস্থিত, ✕ অনুপস্থিত, - খালি)।
   - **সাম্প্রতিক হাজিরা:** সর্বশেষ ৬০টি হাজিরার তালিকা।

3. **আয় ও খরচ (Income & Site Expenses):**
   - সাইটের রানিং বিল / অগ্রিম জমা রেকর্ড।
   - মজুরি ছাড়া দৈনন্দিন মালামাল, যাতায়াত, খাওয়া-দাওয়া, মেশিন ভাড়া ও অন্যান্য খরচ ক্যাটাগরিভিত্তিক ট্র্যাকিং।

4. **স্বয়ংক্রিয় বেতন ও লাভ-ক্ষতির সারাংশ (Summary & Salary Auto-Calculation):**
   - নিট লাভ/ক্ষতি = `মোট আয় − পরিশোধিত বেতন − অগ্রিম − দৈনিক দেওয়া নগদ − সাইট খরচ`
   - প্রতি কর্মীর উপস্থিত দিন, ওভারটাইম, দৈনিক নেওয়া নগদ, অগ্রিম ও পরিশোধের উপর ভিত্তি করে অবশিষ্ট বাকি (Due) হিসাব।
   - মালিক ইচ্ছে করলে উপস্থিত দিন বা মোট প্রাপ্য ম্যানুয়ালি এডিট করতে পারেন।

5. **অফলাইন সাপোর্ট ও PWA (Offline Persistence):**
   - ইন্টারনেট ছাড়াই তথ্য টাইপ করা যায়, ইন্টারনেট এলে অটোমেটিক ফায়ারবেস ক্লাউডে সিঙ্ক হয়।
   - অ্যান্ড্রয়েড ও আইফোনে (iOS Safari) অ্যাপ হিসেবে ইনস্টল করা যায়।

6. **বাংলা ও এক্সেল এক্সপোর্ট (Bengali & CSV Export):**
   - Hind Siliguri ফন্ট ও টাকা চিহ্ন (৳)।
   - UTF-8 BOM যুক্ত CSV এক্সপোর্ট, যা সহজে এক্সেল (MS Excel)-এ কোনো ভাঙা অক্ষরের ঝামেলা ছাড়াই খোলে।
   - `window.print()` প্রিন্ট ও PDF করার সুবিধা।

## 🛠 প্রযুক্তি ও ফ্রেমওয়ার্ক (Tech Stack)

- **Frontend:** React 19 + Vite + Tailwind CSS + Lucide Icons
- **Backend & Database:** Firebase v10 Modular SDK (Authentication + Cloud Firestore with Persistent Local Cache)
- **PWA:** `vite-plugin-pwa` (Manifest, Service Worker, Install Prompt)
- **Styling:** Industrial Dark Theme with Copper (`#c8793f`) & Amber (`#e0a52c`) accents + Light Theme toggle (🌓).

## 📋 সেটিং আপ নির্দেশিকা (Setup Guide)

### ১. ফায়ারবেস প্রজেক্ট কনফিগারেশন (Firebase Setup)
1. [Firebase Console](https://console.firebase.google.com/)-এ নতুন একটি প্রজেক্ট তৈরি করুন।
2. **Authentication** সেকশনে গিয়ে Email/Password প্রোভাইডার চালু (Enable) করুন।
3. **Firestore Database** ক্রিয়েট করুন।
4. `firestore.rules` ফাইল থেকে সিকিউরিটি রুলস আপনার ফায়ারবেস কনসোলে পেস্ট করে পাবলিশ করুন।
5. Web App রেজিস্টার করে আপনার কনফিগ মানগুলো `.env` ফাইলে যুক্ত করুন:

```env
VITE_FIREBASE_API_KEY="your-api-key"
VITE_FIREBASE_AUTH_DOMAIN="your-project.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="your-project-id"
VITE_FIREBASE_STORAGE_BUCKET="your-project.appspot.com"
VITE_FIREBASE_MESSAGING_SENDER_ID="your-sender-id"
VITE_FIREBASE_APP_ID="your-app-id"
```

### ২. প্রথম মালিক অ্যাকাউন্ট তৈরি (First Owner Creation)
1. ফায়ারবেস কনসোল (Firebase Console -> Authentication -> Users)-এ গিয়ে ম্যানুয়ালি আপনার প্রথম ইমেইল ও পাসওয়ার্ড দিয়ে ইউজার যুক্ত করুন।
2. অ্যাপটি চালু করে উক্ত ইমেইল ও পাসওয়ার্ড দিয়ে লগইন করুন।
3. অ্যাপটি সিস্টেমের প্রথম ইউজারকে স্বয়ংক্রিয়ভাবে 👑 **মালিক (Owner)** হিসেবে নথিভুক্ত করবে।
4. পরবর্তীতে মালিক মোডের **'ব্যবহারকারী'** ট্যাব থেকে ফরম্যানদের অ্যাকাউন্ট তৈরি করতে পারবেন।

### ৩. লোকাল ডেভেলপমেন্ট (Local Development)
```bash
# ডিপেন্ডেন্সি ইনস্টল
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev
```

### ৪. ভার্সেল ডিপ্লয়মেন্ট (Vercel Deployment)
1. প্রজেক্টটি GitHub-এ পুশ করুন।
2. [Vercel](https://vercel.com/)-এ ইম্পোর্ট করুন।
3. Environment Variables-এ উপরের `VITE_FIREBASE_*` মানসমূহ যুক্ত করুন।
4. `vercel.json` ফাইল স্পা (SPA) রাউটিং সচল রাখবে।
